🧮 Math Indenter

Math Indenter è un editor matematico avanzato pensato per migliorare la leggibilità delle funzioni matematiche.
Indenta automaticamente le espressioni e assegna colori distintivi alle variabili, facilitando la comprensione anche delle formule più complesse.

✨ Funzionalità principali

• 	✅ Indentazione automatica delle funzioni matematiche

• 	🎨 Colorazione intelligente delle variabili

• 	📄 Esportazione in PDF delle espressioni formattate

• 	🖥️ Interfaccia desktop basata su Electro


📤 Export PDF
Math Indenter permette di esportare le funzioni formattate in PDF, mantenendo colori e indentazione.
